# brzzdev/homebrew-tap

Homebrew formulae for brzzdev's tools.

```sh
brew install brzzdev/tap/perch
```

| Formula | Tool |
| --- | --- |
| `perch` | [Interactive Git branch and worktree switcher](https://github.com/brzzdev/perch) |

Each formula is written by its project's release workflow when a release is published; don't edit them by hand.
